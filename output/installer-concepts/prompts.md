## Pearl

Use case: ui-mockup. Create a polished high-resolution installer design comparison image for OrbitCord, a lightweight Discord desktop app. Input reference: the glossy cobalt blue rounded-square app icon with a white O ring; preserve its identity. Produce TWO large installer window mockups stacked vertically on a neutral presentation background, a macOS DMG Finder installer on top and a Windows installer below, both in the same aesthetic. Small editorial labels outside the windows say "macOS" and "Windows". Both windows fully visible, front-on, crisp legible typography, generous whitespace, refined spacing. macOS: realistic restrained Finder titlebar titled "OrbitCord", main heading "Make yourself at home.", subtitle "Drag OrbitCord into Applications to get started.", existing blue O app icon on left labeled "OrbitCord.app", tasteful thin right arrow in center, native blue Applications folder on right labeled "Applications", tiny footer "Then open OrbitCord from Applications." Keep actual two-icon drag layout obvious. Windows: restrained Windows titlebar with proper window controls, small blue O brand mark, heading "Welcome to OrbitCord", subtitle "A lighter place to hang out.", clean prominent "Install OrbitCord" primary button, subtle secondary "Cancel", small "Ready when you are." text. No feature dashboards, no browser chrome, no large cards, no busy illustration, no marketing claims or fabricated privacy claims. Beautiful realistic production-ready interface design, not wireframe. Direction 01 / Pearl: warm near-white pearl surfaces, faint cool gray hairlines, dark graphite type, cobalt accent. Almost entirely flat backgrounds with a tiny soft blue glow behind icons. macOS feels elegant Apple native; Windows feels quiet Fluent native. Outer presentation background light gray. Label at top "01 — Pearl".
