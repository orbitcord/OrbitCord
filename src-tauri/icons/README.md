# OrbitCord icon

`icon.png` preserves the original circular ring with a glassy macOS background,
edited with the built-in imagegen tool and fitted to a 1024px dock canvas.
The other PNGs, `icon.icns`, and `icon.ico` are resized platform exports.
`trayTemplate.png` uses the original flat ring as an alpha mask for the macOS menu bar.
